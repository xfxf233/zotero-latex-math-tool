# 混排文本的字体与行高对齐原生文本标注

## 问题

overlay 里的文本用 Helvetica/Arial 字体栈、行高 1.4，而 Zotero 原生文本标注用阅读器
自己的字体和行高。同一页上混排标注和原生文本标注并排时，字号视觉大小和行距对不上，
基线也略有偏移。

目标：在 100%/150%/200% 缩放下，混排文本的单行高度、基线与相邻的原生文本标注肉眼一致。

## 方案

- 先量真机：读一个原生 textarea 的 computed style（font-family / font-size / line-height），
  与其渲染后的高度对比，确定 Zotero 实际用的值。
- 优先直接复用该计算值，而不是继续猜字体栈；若原生用的是阅读器内部字体，再决定是
  复制字体栈还是接受近似。
- 改动只在 rich 布局的 CSS 和一个常量（`RICH_LINE_HEIGHT`），不动测量公式。

## 风险

- 改动行高会改变所有已有混排标注的渲染高度，可能让旧 rect 显得偏紧或偏松。
- 字体可用性依赖系统：Linux 上没有 Helvetica，回退结果的宽度本身就不同。

## 验收

- 真机并排对比截图：单行、多行、行内公式混排三种情况。
- 改完后编辑保存的新标注 rect 仍然贴合内容。
