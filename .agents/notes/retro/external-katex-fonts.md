# 复盘：外部字体文件

参见 [否决理由](../rejected/external-katex-fonts.md)。这里只留判断方法。

## 能带走的

1. **体积优化的第一步是确认运行环境能加载什么。** 插件在 xpi 里能访问
   `chrome://<ref>/content/...`，但 PDF reader 的 iframe 文档不在那个协议的作用域里。
   改资源加载方式之前，先在目标文档里确认一个资源真的能取到，再谈省多少 KB。
2. **用户在产品取舍上可能不按"更小更快"投票。** 这里用户要的是字体完整（不子集化），
   体积是次要项。记录否决理由时把这条一起写下来，避免以后又有人拿"减小体积"当理由。
3. **回退要彻底。** 当时同时存在两种加载路径，最容易的错是留了半套 CSS 变量导致局部
   公式字体不对。回退时删干净，比加开关安全。
